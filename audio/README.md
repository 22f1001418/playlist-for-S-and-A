# Drop the songs here

Name the files exactly like the `file:` field in `js/tracks.js`:

```
a1-butterfly.mp3
a2-danger.mp3
a3-dynamite.mp3
a4-euphoria.mp3
a5-ghost.mp3
b1-salaam-aaya.mp3
b2-jab-julo-bareli.mp3
b3-blue.mp3
b4-comethru.mp3
```

Any file that isn't here plays as a **silent reel** — the tape still runs on the
printed duration, so the reels spin, the progress bar moves, and it auto-advances.
Nothing breaks; you just don't hear it.
